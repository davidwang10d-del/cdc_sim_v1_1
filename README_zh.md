# CDC Sim v0 中文主席团指南

CDC Sim 是给模拟联合国危机委员会使用的军事与政治危机推演工具。主席团可以用它管理地图、部队、补给、士气、危机更新和 SITREP 情势报告。

系统核心统一定义战术指令、战斗姿态及两者的互动。DLC 只保存战役数据和剧本特有规则，例如地图、参战部队、武器、营种、外交关系、委员会材料和战区参数；DLC 不得重新定义核心指令或姿态。

当前版本的地图组件、底图和 DLC ZIP 导出需要网络连接。正式开会前请提前测试场地网络。

## 快速启动

1. 打开项目文件夹。
2. 第一次使用时，双击 `INSTALL_OR_REPAIR.bat`。
3. 等待显示 `Install/repair complete`。
4. 双击 `START_CDC_SIM.bat`。
5. 保持黑色窗口打开。
6. 浏览器打开 `http://127.0.0.1:5000/zh`。
7. 点击要运行的 DLC 剧本。

## 会前流程

1. 打开状态检查：`http://127.0.0.1:5000/status`，确认系统可用。
2. 打开中文界面并选择剧本：`http://127.0.0.1:5000/zh`。
3. 等待地图加载。
4. 不要立刻点击 Play。
5. 点击 `MUN`，查看委员会名称、代表角色、规则、阵营状态。
6. 点击 `Saves`（存档）。
7. 在 `Checkpoint 1`（检查点 1）点击 `Save here`（保存到此处），手动保存初始状态。
8. 系统不会自动保存；只有点击保存按钮才会写入进度。

## 委员会运行流程

建议节奏：

1. 代表辩论时保持 `Pause`。
2. 收取指令。
3. 主席团判断指令成功、部分成功或失败。
4. 在 `MUN` 面板录入裁定。
5. 如有军事行动，再移动部队。
6. 发布公开危机更新。
7. 在 `Saves` 中手动保存。
8. 继续辩论。

## MUN 面板裁定方法

点击 `MUN` 后填写：

- `Public update / directive title`：公开更新标题。
- 正文框：一到两句话的危机更新。
- `Faction or GLOBAL`：受影响阵营。全体影响写 `GLOBAL`。
- 效果：
  - `No mechanical effect`：只发布剧情。
  - `Morale +/-`：士气、合法性、宣传、恐慌。
  - `Supply +/-`：补给、燃料、弹药、援助、制裁。
  - `Fatigue +/-`：疲劳、休整、疾病、天气。
  - `Combat multiplier`：临时战斗倍率。
  - `Speed multiplier`：临时机动倍率。
- `Value`：数值。
  - 小成功：`+3` 到 `+5`。
  - 明显成功：`+8` 到 `+12`。
  - 重大事件：`+15` 到 `+25`。
  - 小倍率：`1.1` 或 `0.9`。
  - 强倍率：`1.2` 或 `0.8`。
- 勾选公开发布则代表可见；取消勾选则为主席团私密记录。
- 点击 `Apply Adjudication`。

## 手动保存与恢复

- 本系统不自动保存。下达指令、空投、主席团裁定、数值修改、外交调整和重置剧本都不会写入存档。
- 每次挂载 DLC 都从该 DLC 编写的初始状态开始，不会静默读取旧存档。
- 点击 `Saves` 可查看三个手动检查点。每个检查点会显示是否为空、保存时间、推演时间、部队数量，以及 DLC 或规则是否兼容。
- 空检查点显示 `Save here`；已有存档显示 `Overwrite`，覆盖前会再次确认。
- 点击 `Restore` 会覆盖当前推演状态，恢复前会再次确认，恢复后系统保持暂停。
- `Reset scenario` 与读取存档分开；它恢复 DLC 初始状态，而且不会自动生成备份。
- 关闭程序或切换 DLC 前，请手动保存；上一次手动保存之后的更改会丢失。

## 作战指令：任务 + 姿态

选中部队后，`Operational Order` 面板把两项控制放在同一个位置：

- `Task`（任务）决定部队“做什么、去哪里”。
- `Combat Stance`（战斗姿态）决定部队“如何执行”，包括火力纪律、速度、隐蔽、侦察和战斗倍率。
- 更换任务不会自动改变姿态；更换姿态也不会取消当前任务。

核心任务：

- `Hold`：停止并清除路线，保留当前姿态。
- `Relocate`：直接移动到一个目标点，途中不主动远程开火，但保留近距离自卫。
- `Planned Route`：按多个航点移动，交战规则与 Relocate 相同。
- `Assault`：向目标推进，发现武器射程内敌军时停下接敌，接触解除后继续推进。
- `Defend Here`：停止、恢复并按正常速度构筑阵地，保留当前姿态。
- `Fortify`：消耗补给并增加疲劳，加速构筑阵地，完成后转为 Defend Here。

Relocate 和 Planned Route 会压制主动远程开火，不受所选姿态影响；Hold Fire 也会让其他任务停止远程开火。任何任务都保留近距离自卫。Defend 和 Fortify 在所有姿态下都能构筑工事；Defensive 姿态会额外提供基础掩护。

## 制作自己的 DLC

1. 点击主界面 `Editor`。
2. 按左侧顺序填写：
   - `Scenario & Map`：剧本名称、地图中心、边界、可选地图文件。
   - `Committee`：委员会名称、规则、角色、胜利目标、主席备注。
   - `Diplomacy`：初始同盟阵营。
   - `Units`：部队、坐标、人数、装备水平、核心默认姿态、编成。
   - `Battalion Types`：营种类型，例如步兵、装甲、炮兵、工兵、民兵。
   - `Weapons`：武器名称和射程。
   - `Export`：检查并导出。
3. 点击 `Check Package`。
4. 点击 `Export DLC Zip`。
5. 把 zip 解压到项目的 `dlc` 文件夹。
6. 给解压后的文件夹改英文 ID，例如 `taiwan_2028` 或 `sahel_crisis`。
7. 刷新主界面，新的 DLC 会出现在列表中。

编辑器中的 `Simulation Rules` 只用于战役专有数值和特殊规则。核心战术指令与战斗姿态为只读内容，不会写进导出的 `rules.json`。

## 核心姿态说明

- `DEFENSIVE`：防御固守。推荐正规军默认使用。
- `AGGRESSIVE`：主动接敌，适合进攻命令。
- `STEALTH`：隐蔽行动，更难发现但速度较慢。
- `RECON`：侦察警戒，更容易发现敌方。
- `RESERVE`：预备队，休整、恢复士气和补给。
- `HOLD_FIRE`：停火待命，避免远程主动开火。

## 常见问题

- 浏览器无法连接：确认 `START_CDC_SIM.bat` 黑色窗口还开着。
- 剧本列表为空：确认 DLC 文件夹在 `dlc` 内，并且有 `scenario.json`。
- 地图加载慢：高程和道路文件较大，等待即可。
- 炮击失败：部队必须拥有当前 DLC `rules.json` 指定的炮击能力，同时还需要足够补给且目标在射程内。
- 裁定输错：读取上一个存档并重新输入。
