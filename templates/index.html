1. Temporary unit effect

2. Set unit personnel now

Immediately replaces the selected unit’s current personnel with the entered whole number. Equipment, supply, morale, and composition are unchanged; 0 leaves the unit with no effective strength.

Takes effect immediately and is not saved automatically.

3. City influence areas

Set circular city areas. Influence 0 has no effect; 1 represents maximum New York-scale city complexity. Armies inside are affected through terrain, cover, frontage, concealment, movement, and fatigue.

Changes take effect immediately and are written to progress only in a manual checkpoint.

4. Province politics and civilian sentiment

Each province stores a separate record for every faction. Sentiment −1 means maximum opposition, 0 is neutral/indifferent, and +1 is maximum support. Occupation is 0–1; hostile factions can produce contested control.
